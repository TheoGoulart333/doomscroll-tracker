# Contribuindo com o Doomscroll Tracker

Obrigado pelo interesse em contribuir! 🎉

## Como começar

1. **Fork** o repositório no GitHub
2. **Clone** seu fork:
   ```bash
   git clone https://github.com/SEU_USUARIO/doomscroll-tracker.git
   cd doomscroll-tracker
   ```
3. **Carregue no Chrome** (modo desenvolvedor) conforme o README
4. **Crie uma branch** para sua feature:
   ```bash
   git checkout -b feature/nome-da-feature
   ```
5. **Faça suas alterações** e commit seguindo o padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/):
   ```
   feat: adiciona X
   fix: corrige Y
   docs: atualiza README
   style: formata código
   refactor: reorganiza background.js
   ```
6. **Abra um Pull Request** com descrição clara do que foi feito

## Boas práticas

- Mantenha **zero dependências externas** (a extensão roda 100% local)
- Respeite a política de **privacidade**: nenhum dado pode sair do navegador
- Teste em Chrome mais recente antes de submeter PR
- Adicione screenshot/GIF se a mudança for visual
- Comente código complexo em português ou inglês
